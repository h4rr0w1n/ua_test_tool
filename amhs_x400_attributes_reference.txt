# AMHS X.400 Attributes Reference Document
## Based on ICAO Doc 020 (Manual on Air Traffic Management Systems) and EUR Doc 047

### Overview
This document lists all required and optional AMHS X.400 attributes as defined in ICAO documentation
for Aeronautical Message Handling System (AMHS) implementation.

================================================================================

## SECTION 3: ATTRIBUTE REQUIREMENTS BY MESSAGE TYPE
================================================================================

### 3.1 Basic IPM Message (Standard ATS Message)
REQUIRED ATTRIBUTES:
- recipient (X400_RECIP_PRIMARY)
- subject (X400_S_SUBJECT)
- priority (X400_N_PRIORITY or ATS_S_PRIORITY_INDICATOR)
- content/body (X400_S_BODY_DATA via BodypartIA5Text)
- filing-time (ATS_S_FILING_TIME) - for ATS messages

OPTIONAL ATTRIBUTES:
- optional-heading-info (ATS_S_OPTIONAL_HEADING_INFO)
- originator-reference (can be stored in OHI)
- cc-recipients (X400_RECIP_CC)
- bcc-recipients (X400_RECIP_BCC)
- notification-request (X400_N_NOTIFICATION_REQUEST)
- report-request (X400_N_REPORT_REQUEST)

### 3.2 Extended IPM Message
REQUIRED ATTRIBUTES (in addition to Basic IPM):
- precedence (X400_N_PRECEDENCE) - values: 14, 28, 57, 71, 107
- body-part-type = general-text-body-part (X400_T_GENERAL_TEXT)
- authorization-time (ATS_S_AUTHORIZATION_TIME)

OPTIONAL ATTRIBUTES:
- responsibility (ATS_S_RESPONSIBILITY) - "responsible" or "not-responsible"
- charset-reg-number (ATS_S_CHARSET_REG_NUMBER)
- charset-repertoire (ATS_S_CHARSET_REPERTOIRE)
- conversion-with-loss-prohibited (ATS_S_CONVERSION_WITH_LOSS_PROHIBITED)
- notify-control-position (ATS_S_NOTIFY_CONTROL_POSITION)

### 3.3 Message with File Attachment (FTBP)
REQUIRED ATTRIBUTES:
- body-part-type = ftbp or includes ftbp
- ftbp-file-name (X400_S_FTBP_FILENAME)
- ftbp-content (file content as byte array)

OPTIONAL ATTRIBUTES:
- ftbp-content-description (X400_S_FTBP_CONTENT_DESCRIPTION)

### 3.4 Multi-part Message
REQUIRED ATTRIBUTES:
- body-part-type = comma-separated list (e.g., "ia5-text,ftbp")
- Each body part must have appropriate content

## SECTION 4: PRIORITY MAPPING
================================================================================

### ATS Priority Codes to X.400 Priority
| ATS Code | Description        | X.400 Priority Value |
|----------|--------------------|----------------------|
| KK       | Highest Priority   | HIGH_PRIORITY (2)    |
| GG       | High Priority      | HIGH_PRIORITY (2)    |
| FF       | Normal Priority    | NORMAL_PRIORITY (1)  |
| DD       | Low Priority       | LOW_PRIORITY (0)     |
| SS       | Special/Survival   | LOW_PRIORITY (0)     |

### Extended Precedence Values
| Precedence | Description              | Maps To            |
|------------|--------------------------|--------------------|
| 14         | Lowest                   | LOW_PRIORITY       |
| 28         | Low                      | NORMAL_PRIORITY    |
| 57         | Medium                   | HIGH_PRIORITY      |
| 71         | High                     | HIGH_PRIORITY      |
| 107        | Highest                  | HIGH_PRIORITY      |

## SECTION 5: EDITABLE ATTRIBUTES PER ICAO RULES
================================================================================

According to ICAO Doc 020 and EUR Doc 047, the following attributes MUST be 
editable by the user/application when composing AMHS messages:

### MUST BE EDITABLE:
1. recipient - Primary recipient O/R address
2. subject - Message subject line
3. content - Message body content
4. priority - Message priority (ATS codes or X.400 values)
5. filing-time - ATS filing time
6. body-part-type - Type of body part(s)
7. optional-heading-info - OHI text
8. originator-reference - Originator reference text
9. precedence - For extended IPMs
10. authorization-time - For extended IPMs
11. responsibility - For extended IPMs
12. charset configuration - For general text body parts
13. eit configuration - For encoded information types
14. ftbp configuration - For file attachments
15. cc-recipients - Carbon copy recipients
16. bcc-recipients - Blind copy recipients
17. notification-request - IPN request settings
18. report-request - Delivery report request settings

### SYSTEM-GENERATED (NOT EDITABLE):
1. message-identifier - Generated by system
2. ipm-identifier - Generated by system
3. submission-time - Generated at submission
4. delivery-time - Generated at delivery
5. sequence-number - Generated by message store
6. is-extended - Determined by message type

### Setting Attributes via ISODE API:
- String parameters: message.setStringparam(AMHS_att.ATS_S_*, value)
- Integer parameters: message.setIntParam(X400_att.X400_N_*, value)
- Body parts: message.addBodypart(BodypartXXX)

### Common AMHS_att Constants Used:
- AMHS_att.ATS_S_FILING_TIME
- AMHS_att.ATS_S_PRIORITY_INDICATOR
- AMHS_att.ATS_S_OPTIONAL_HEADING_INFO
