## 🇬🇧 English Guide: Running the AMHS UA Test Tool with GUI on Docker

### Prerequisites
1. **Docker**: Ensure Docker is installed and running.
2. **X Server**: This GUI application needs an X server to display windows from inside Docker.

### Step 1: Build the Docker Image

```bash
docker build -t amhs-ua-test-tool .
```

### Step 2: Run the Container with GUI Support

**Windows:**
1. Install an X server such as [VcXsrv](https://sourceforge.net/projects/vcxsrv/) or [Xming](https://sourceforge.net/projects/xming/).
2. Start the X server and allow connections from local clients.
3. Run the container:

```bash
docker run --rm -it -e DISPLAY=host.docker.internal:0 amhs-ua-test-tool
```

If `host.docker.internal` does not work, use your Windows host IP address.

**Linux:**

```bash
xhost +local:docker

docker run --rm -it -e DISPLAY=$DISPLAY -v /tmp/.X11-unix:/tmp/.X11-unix amhs-ua-test-tool
```

**macOS:**
1. Install [XQuartz](https://www.xquartz.org/).
2. In XQuartz preferences, enable **Allow connections from network clients** and restart XQuartz.
3. Allow local access:

```bash
xhost +localhost
```

```bash
docker run --rm -it -e DISPLAY=host.docker.internal:0 amhs-ua-test-tool
```

### Step 3: Verify the Application
The Swing GUI should open on your host machine. If you need to keep files generated by the container, mount a host directory with `-v`.

## 🇻🇳 Hướng dẫn Tiếng Việt: Chạy AMHS UA Test Tool (GUI) trên Docker

### Yêu cầu
1. **Docker**: Đã cài và đang chạy.
2. **X Server**: Ứng dụng GUI cần X Server để hiển thị cửa sổ từ Docker.

### Bước 1: Build Docker Image

```bash
docker build -t amhs-ua-test-tool .
```

### Bước 2: Chạy Container với GUI

**Windows:**
1. Cài đặt X server như [VcXsrv](https://sourceforge.net/projects/vcxsrv/) hoặc [Xming](https://sourceforge.net/projects/xming/).
2. Khởi động X server và cho phép kết nối từ máy local.
3. Chạy container:

```bash
docker run --rm -it -e DISPLAY=host.docker.internal:0 amhs-ua-test-tool
```

Nếu `host.docker.internal` không hoạt động, dùng địa chỉ IP của máy Windows.

**Linux:**

```bash
xhost +local:docker

docker run --rm -it -e DISPLAY=$DISPLAY -v /tmp/.X11-unix:/tmp/.X11-unix amhs-ua-test-tool
```

**macOS:**
1. Cài đặt [XQuartz](https://www.xquartz.org/).
2. Trong XQuartz preferences, bật **Allow connections from network clients** rồi khởi động lại XQuartz.
3. Cho phép kết nối:

```bash
xhost +localhost
```

```bash
docker run --rm -it -e DISPLAY=host.docker.internal:0 amhs-ua-test-tool
```

### Bước 3: Xác minh
Giao diện Swing sẽ hiển thị trên máy của bạn. Nếu muốn giữ dữ liệu do container tạo, mount thư mục host với `-v`.
